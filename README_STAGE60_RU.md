# Stage 60 — filter alignment + summary order

## Что меняет

1. Кнопки `Показать результаты` и `Сбросить фильтр` становятся по высоте как обычные ячейки фильтра.
2. Порядок фильтра:
   - 1 строка: Поиск / Федеральная земля / Город
   - 2 строка: Индекс / Суд / Тип объекта / Использование
   - 3 строка: Радиус / Оценочная стоимость / Жилая площадь / Участок
   - 4 строка: Торги от / Торги до / Статус / Памятник архитектуры
   - 5 строка: Ценовые границы / № термина / Показать результаты / Сбросить фильтр
3. Статистика переносится между активными фильтрами и картой.

## Установка

Скопировать из архива с заменой:

```txt
components/FilterBar.tsx
scripts/stage60_patch_summary_and_filter_css.mjs
```

Запустить:

```powershell
cd D:\Projects\zvg_frontend_mvp
node .\scripts\stage60_patch_summary_and_filter_css.mjs
npm run build
```
