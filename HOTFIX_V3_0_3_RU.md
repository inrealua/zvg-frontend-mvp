# Site AI v3.0.3 hotfix

Исправляет TypeScript-конфликт после временного сохранения legacy enum `UK` в Prisma.

- База может временно содержать `DE/RU/EN/UK`.
- Публичный сайт по-прежнему работает только с `DE/RU/EN`.
- Старые `UK`-переводы полностью игнорируются UI и не используются как fallback.
- Патч не меняет Prisma schema и не затрагивает данные.

Установка: распаковать архив поверх `F:\ZVG-SITE-GIT` с заменой файла, затем удалить `.next` и выполнить `npm run build`.
