# Stage 21 — улучшение фильтра и исправление авторизации избранного

Этот пакет исправляет замечания по дизайну фильтра и делает API избранного/сохранённых поисков более устойчивым к проблемам с cookie.

## Что изменено

- Цена теперь один двойной ползунок “от—до”.
- Wohnfläche теперь один двойной ползунок “от—до”.
- Grundstück теперь один двойной ползунок “от—до”.
- Bundesland заменён на компактный выпадающий многовыбор.
- Тип объекта заменён на компактный выпадающий многовыбор.
- Использование заменено на компактный выпадающий многовыбор.
- API избранного теперь читает cookie напрямую из `NextRequest`, а не только через `cookies()`.
- API сохранённых поисков исправлен аналогично.

## Как поставить

1. Сделай backup:

```powershell
Copy-Item -Recurse D:\Projects\zvg_frontend_mvp D:\Projects\zvg_frontend_mvp_backup_stage21
```

2. Распакуй архив.

3. Скопируй папки `app`, `components`, `lib` поверх проекта:

```txt
D:\Projects\zvg_frontend_mvp
```

4. Проверь сборку:

```powershell
cd D:\Projects\zvg_frontend_mvp
npm run build
```

5. Проверь локально:

```powershell
npm run dev
```

6. Выйди из пользовательского аккаунта и войди снова. Это важно, если на Vercel раньше был другой `USER_SESSION_SECRET`.

7. Проверь добавление в избранное.

8. Отправь на GitHub:

```powershell
git add .
git commit -m "Improve filters design and fix favorite auth"
git push
```

## Важно для Vercel

Проверь, что в Vercel есть переменная:

```txt
USER_SESSION_SECRET
```

Если её не было, добавь длинную случайную строку и сделай Redeploy. После смены секрета старые пользовательские сессии станут недействительными, поэтому нужно будет заново войти в аккаунт.
