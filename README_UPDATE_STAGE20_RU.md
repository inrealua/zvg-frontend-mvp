# Stage 20 — правки UX после проверки сайта

Этот пакет закрывает замечания по главной странице, карте, фильтрам, архиву и избранному.

## Что исправлено

1. Карта теперь поддерживает масштабирование колесом мыши.
2. На главной странице карта вынесена под фильтры и статистику, над списком объектов.
3. Ссылка меню `Карта` теперь ведёт на отдельную страницу `/map` с большой картой и фильтрами сбоку.
4. Добавлена вкладка `/archive`.
5. Объекты с датой аукциона раньше сегодняшнего дня автоматически уходят в архив.
6. Фильтр Bundesland теперь позволяет выбрать несколько земель одновременно.
7. Фильтр типов недвижимости теперь позволяет выбрать несколько типов одновременно.
8. Фильтр использования теперь позволяет выбрать несколько вариантов одновременно.
9. Цена и площади заменены на ползунки.
10. Убрано отдельное поле `Ort/PLZ für Radius`.
11. Радиус теперь строится от выбранного `Город` или `PLZ`.
12. Из сортировки удалены `Wohnfläche: больше` и `Недавно обновлённые`.
13. Из публичного фильтра статуса удалены `Продан`, `Архив`, `Неизвестно`.
14. Кнопка избранного теперь явно отправляет cookies через `credentials: "same-origin"` и показывает ошибку без тихого сбоя.

## Как поставить

1. Сделай backup:

```powershell
Copy-Item -Recurse D:\Projects\zvg_frontend_mvp D:\Projects\zvg_frontend_mvp_backup_stage20
```

2. Распакуй архив `zvg_stage20_user_fixes_update_files.zip`.

3. Скопируй папки и файлы из архива поверх проекта:

```txt
app
components
lib
README_UPDATE_STAGE20_RU.md
FILES_TO_REPLACE_STAGE20.md
```

4. Проверь сборку:

```powershell
cd D:\Projects\zvg_frontend_mvp
npm run build
```

5. Проверь локально:

```powershell
npm run dev
```

Открой:

```txt
http://localhost:3000
http://localhost:3000/map
http://localhost:3000/archive
```

6. Отправь на GitHub:

```powershell
git add .
git commit -m "Improve filters map archive and favorites UX"
git push
```

`npm run db:push` для этого этапа не нужен, потому что схема базы не меняется.
