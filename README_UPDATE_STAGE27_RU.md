# Stage 27 — главная страница без перегруза + расширенная карта

Этот пакет исправляет замечания по дизайну после Stage 26.

## Что изменено

- На главной больше нет большого расширенного фильтра.
- На главной добавлен компактный быстрый поиск.
- Добавлены две логики:
  - **Schnell suchen** — ищет по быстрым параметрам на главной.
  - **Erweiterte Suche** — переводит на `/map` с расширенной формой.
- `/map` теперь является основной страницей расширенного поиска.
- Расширенный фильтр больше не использует выпадающие многофункциональные панели, которые перекрывали форму.
- Bundesland / Objektart / Nutzung теперь представлены аккуратными chip-checkbox блоками.
- Фильтр на странице карты скроллится вместе со всей страницей, не фиксируется и не зависает.
- На главной остаются:
  - быстрый поиск;
  - карта;
  - Top 12 текущих объектов.
- Маркеры карты стали более различимыми, но остались в спокойной палитре.
- Popup-карточка на карте получила больше информации: тип, название, адрес, дата, Verkehrswert, кнопка Details.
- Главный посыл сайта изменён на: **Alle gerichtlichen Versteigerungen an einem Ort.**

## Как установить

1. Сделать backup:

```powershell
Copy-Item -Recurse D:\Projects\zvg_frontend_mvp D:\Projects\zvg_frontend_mvp_backup_stage27
```

2. Распаковать архив.

3. Скопировать папки `app` и `components` поверх проекта:

```txt
D:\Projects\zvg_frontend_mvp
```

4. Проверить:

```powershell
npm run build
npm run dev
```

5. Если всё работает:

```powershell
git add .
git commit -m "Simplify homepage and move advanced search to map"
git push
```

`npm run db:push` не нужен — база данных не менялась.
